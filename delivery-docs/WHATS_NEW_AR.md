# مِرصاد — تحديث اللغة الإنجليزية والإضافات الاحترافية

تاريخ التحديث: ١ نوفمبر ٢٠٢٦. التحديث على الواجهة فقط؛ قاعدة البيانات ومسارات الـ API ووظيفة الذكاء الاصطناعي لم تتغيّر، فلا حاجة لتشغيل أي migration جديد.

## ١. التبديل بين العربية والإنجليزية

- زر **EN / ع** في الشريط العلوي، أو اختصار **L**، أو من نافذة «حسابي».
- عند اختيار English تنقلب الواجهة كاملة إلى اليسار-لليمين (LTR): القائمة الجانبية، الجداول، الأسهم، النوافذ، التنبيهات، وقائمة الجوال.
- الاختيار يُحفظ في المتصفح ويُطبَّق قبل أول رسم للصفحة (بدون وميض).
- تُترجم أيضًا: رسائل أخطاء الخادم (حسب رمز الخطأ)، رسائل سجل الإجراءات التي تكتبها قاعدة البيانات، أسماء الحالات والأولويات والتصنيفات، والتواريخ والأوقات.
- ما يكتبه المستخدمون (عنوان البلاغ، الوصف، الملاحظات، رد الذكاء الاصطناعي) يبقى بلغته الأصلية، ويُعرض باتجاهه الصحيح تلقائيًا حتى داخل الواجهة الإنجليزية.
- إجابات الأسئلة الخمسة تُرسل للذكاء الاصطناعي بالعربية دائمًا مهما كانت لغة الواجهة، حتى تبقى معايير التصنيف ثابتة.

### إضافة نص جديد للواجهة
1. اكتبي النص بالعربي داخل `tr('...')` في `public/mirsad.js`.
2. أضيفي سطر ترجمته في `public/mirsad-i18n.js`.
3. شغّلي `node tests/i18n.mjs` — يفشل الاختبار ويذكر أي نص بدون ترجمة.

## ٢. إضافات تجعل التجربة أكثر احترافية

| الإضافة | الوصف |
|---|---|
| فلاتر سريعة بالحالة | شرائح (الكل / جديد / قيد العمل / بانتظار الاستلام / مكتمل) مع عدد البلاغات لكل حالة |
| ترتيب البلاغات | الأحدث، الأقدم، الأعلى أولوية، حسب الحالة |
| تصدير CSV (للفنيين) | يصدّر النتائج المعروضة حاليًا بترميز يفتح العربية صحيحًا في Excel، مع حماية من حقن الصيغ |
| روابط مباشرة | لكل صفحة وبلاغ رابط مثل `#/details/12`؛ زر الرجوع في المتصفح يعمل، وزر «نسخ رابط البلاغ» في صفحة التفاصيل |
| طباعة البلاغ | زر طباعة يُخرج صفحة نظيفة بدون القوائم والأزرار |
| الوقت النسبي | «قبل ٥ دقائق» في الجدول والسجل، والتاريخ الكامل يظهر عند الوقوف بالماوس |
| عمر البلاغ وتاريخ إنشائه | في الجدول وفي بيانات البلاغ |
| بطاقات إحصاءات قابلة للنقر | «أولوية عالية» تفتح القائمة مفلترة بالبلاغات العالية، وهكذا |
| تحية حسب الوقت | «صباح الخير / مساء الخير» بتوقيت الرياض |
| عدّاد الأحرف | في عنوان البلاغ والتفاصيل والملاحظات |
| اختصارات لوحة المفاتيح | `/` بحث، `N` بلاغ جديد، `G ثم D` لوحة التحكم، `G ثم T` البلاغات، `L` اللغة، `?` قائمة الاختصارات |
| خطوات تعريفية للزائر | ثلاث خطوات توضح كيف يعمل مرصاد في الصفحة الرئيسية قبل تسجيل الدخول |
| رقم الجوال قابل للاتصال | الضغط عليه يفتح الاتصال مباشرة من الجوال |
| رسالة دخول أوضح | «البريد أو كلمة المرور غير صحيحة» بدل الرسالة العامة |
| صيغ جمع عربية صحيحة | «بلاغ واحد، بلاغان، ٥ بلاغات، ١١ بلاغ» |
| إتاحة الوصول | زر «تخطَّ إلى المحتوى» لمستخدمي لوحة المفاتيح وقارئات الشاشة، وبطاقات الإحصاء قابلة للتنقل بالـ Tab |

إصلاحات صغيرة: ألوان الاحتفال بعد قبول التسليم أصبحت بألوان الهوية البترولية، وصفحة «مهامي» تعتمد على معرّف الفني بدل الاسم.

## ٣. الملفات المعدّلة والجديدة

| الملف | التغيير |
|---|---|
| `public/mirsad.js` | نظام الترجمة `tr()`، كل نصوص الواجهة، والإضافات أعلاه |
| `public/mirsad-i18n.js` | **جديد** — القاموس الإنجليزي (≈ 380 نصًا) |
| `app/shell.html` | **جديد** — مصدر هيكل الواجهة القابل للتعديل بسهولة |
| `scripts/build-shell.mjs` | **جديد** — يولّد `app/shell.ts` من `app/shell.html` (`pnpm shell`) |
| `app/shell.ts` | مولَّد: زر اللغة، اختصارات، تخطّي المحتوى |
| `app/workspace.tsx` | يحمّل القاموس قبل الواجهة |
| `app/layout.tsx` | يضبط اللغة والاتجاه والوضع الليلي قبل أول رسم |
| `app/globals.css` | خصائص CSS منطقية تعمل بالاتجاهين + أنماط الإضافات الجديدة |
| `public/palette-petrol.css`, `public/palette-purple.css` | نفس تحويل الاتجاهات |
| `tests/i18n.mjs` | **جديد** — يتحقق أن كل نص مترجم وأن المتغيرات متطابقة |
| `tests/notifications-ui.mjs`, `tests/ticket-impact.mjs` | تحديث بيئة الاختبار لدالة `tr` |
| `package.json` | أوامر `pnpm shell` و `pnpm test:ui` |

## ٤. التحقق

- `node tests/i18n.mjs`, `tests/priority-ui.mjs`, `tests/notifications-ui.mjs`, `tests/ticket-impact.mjs` — كلها ناجحة.
- جُرّبت الواجهة في المتصفح ببيانات تجريبية محاكاة (بدون Supabase) بالعربي والإنجليزي، فاتح وليلي، كمبيوتر وجوال: التنقل، الروابط المباشرة وزر الرجوع، الفلاتر، الترتيب، البحث، التصدير، الاختصارات، ورسائل الأخطاء — بدون أخطاء في الـ Console.
- **لم يُشغَّل `pnpm build` في بيئة التحديث** لعدم توفر تنزيل المكتبات هناك. شغّليه على جهازك بعد `pnpm install --frozen-lockfile` وقبل النشر.
